# 스토리 모드 레벨 디자인 초안

작성일: 2026-10-15

상태: 논의용 초안. 이 문서는 게임 동작을 변경하지 않는다.

## 의도와 확정된 방향

스토리 모드는 기존 당구 조작과 점수, 쿠션, 파울, 아이템 규칙을 바탕으로 스테이지마다 다른 득점 조건을 공략하는 도전형 모드다. 정답이 하나인 배치 퍼즐은 만들지 않는다. 첫 클리어 목표는 약 45~60분이며, 4챕터에 4스테이지씩 총 16개 스테이지를 둔다.

- 스테이지를 넘을 때 총점, 남은 기회, 아이템, 아이템 게이지를 이어받는다.
- 스테이지 목표는 **해당 스테이지에서 인정받은 점수**로 계산한다. 이전 스테이지에서 얻은 점수만으로 즉시 통과하지 않는다.
- 실패하면 현재 챕터 시작 상태로 돌아간다. 챕터 시작 상태에는 점수, 기회, 아이템, 보상 진행도가 포함된다.
- 각 스테이지는 기본 규칙에서 달라지는 조건을 명시한다. 뒤에서는 이미 배운 조건을 조합한다.

## 현재 게임과의 접점

현재 구현된 모드는 무한/클래식이며 스토리 모드는 아직 없다. 기본 득점은 목표 공을 맞히기 전 쿠션 0/1/2/3회에서 각각 100/200/400/800점이다. 깨끗한 득점 샷은 기회를 3으로 회복한다. 파울 공에 닿으면 해당 샷 득점이 무효가 되고 기회를 잃는다. 위험 샷은 쿠션 1/2회에 1,000/10,000점이 가능하지만, 그 샷에서 파울이 나면 누적 점수와 아이템 게이지가 0이 된다. 아이템은 공 이동, 파울 제거, 위험 샷이다.

이 때문에 스토리 모드 목표는 현재 누적 총점만 확인해서는 안 된다. 또한 기회가 득점마다 전부 회복되는 규칙을 그대로 쓰면 챕터 간 기회 관리가 약해진다. 아래 수치와 회복량은 플레이 테스트에서 반드시 조정한다.

## 진행과 판정

1. 스테이지 입장 시 목표 진행량 `stage_points`를 0으로 시작한다. 화면에는 `이번 목표: +N점`, `이번 획득: +M점`, `총점`을 따로 보여준다.
2. 샷이 완전히 끝난 뒤, 해당 스테이지에서 유효하게 얻은 점수가 목표 이상이면 클리어한다. 한 샷의 초과 점수는 총점에 남지만 다음 스테이지의 목표 달성량으로 미리 계산하지 않는다.
3. 일반 득점은 총점과 `stage_points`에 함께 반영한다. `위험 계약`에서는 위험 샷 득점만 `stage_points`에 반영한다. 파울 세금은 총점과 `stage_points`에서 차감하되 각각 0 아래로 내려가지 않는다. 위험 샷 파울은 기존대로 총점과 아이템 게이지를 0으로 만들고 `stage_points`도 0으로 만든다.
4. 기회가 0이 되면 현재 챕터의 1스테이지와 챕터 시작 상태로 돌아간다. 챕터 시작 상태는 해당 챕터에 처음 진입할 때 한 번 저장하고, 재시도 중에는 덮어쓰지 않는다.
5. 각 규칙 변화는 시작 전 안내하고 플레이 중 HUD에서 다시 볼 수 있다. 무효 득점은 왜 무효였는지 즉시 설명한다.

## 규칙 변화 카드

| 카드 | 플레이어에게 보이는 규칙 | 판정 |
| --- | --- | --- |
| 쿠션 1+ | 목표 공 전에 쿠션을 한 번 이상 맞혀야 득점 | 0쿠션 목표 적중은 점수 0. 파울은 아니다. |
| 쿠션 2+ | 목표 공 전에 쿠션을 두 번 이상 맞혀야 득점 | 0~1쿠션 목표 적중은 점수 0. 파울은 아니다. |
| 파울 세금 | 파울 시 확정 총점도 추가로 잃음 | 샷 득점 무효와 기회 손실에 더해 총점 200점 차감, 하한 0. 위험 샷 파울은 기존의 총점 0 규칙이 우선한다. |
| 기회 절약 | 득점해도 기회가 전부 회복되지 않음 | 깨끗한 득점 샷마다 기회 1회 회복, 최대 3. |
| 위험 계약 | 위험 샷으로 얻은 점수만 이번 목표에 반영 | 일반 득점은 총점에 남지만 이번 목표 진행에는 반영하지 않는다. 위험 샷 아이템을 확보할 경로를 스테이지 시작 전에 보장한다. |

이 카드들은 첫 등장 시 하나씩 소개한다. 여러 카드를 조합하는 레벨은 각 카드의 우선순위와 아이템 획득 가능성을 검증한 뒤 사용한다. `위험 계약`은 자원 소프트락 가능성이 가장 크므로, 시제품에서 해결되지 않으면 다른 득점 조건으로 교체한다.

## 16개 스테이지 초안

목표 점수는 **입장 후 추가 득점**이다. 아래 숫자는 밸런스 확정값이 아니라 첫 플레이 테스트용 시작값이다. 각 챕터는 새 규칙 소개 → 응용 → 자원 판단 → 종합의 흐름을 갖는다.

| 챕터 | 스테이지 | 목표 | 규칙 변화 | 의도와 캐릭터 안내 |
| --- | --- | ---: | --- | --- |
| 1. 계약의 시작 | 1-1 첫 득점 | +300 | 기본 규칙 | 목표와 총점의 차이를 소개한다. |
|  | 1-2 벽의 값 | +500 | 쿠션 1+ | 쿠션을 이용한 득점을 익힌다. |
|  | 1-3 붉은 공 | +700 | 파울 세금 | 파울 위험과 공 이동 아이템의 가치를 보여준다. |
|  | 1-4 첫 시험 | +900 | 쿠션 1+ · 파울 세금 | 앞선 두 조건을 함께 적용한다. |
| 2. 아슬아슬한 여유 | 2-1 적은 회복 | +800 | 기회 절약 | 깨끗한 샷도 기회를 완전히 되돌리지 않음을 알린다. |
|  | 2-2 두 번의 벽 | +1,000 | 쿠션 2+ | 고배율 샷을 유도한다. |
|  | 2-3 선택의 대가 | +1,100 | 기회 절약 · 파울 세금 | 안전한 득점과 높은 점수 사이에서 선택한다. |
|  | 2-4 여유 없는 테이블 | +1,400 | 쿠션 2+ · 기회 절약 | 챕터의 배운 조건을 종합한다. |
| 3. 아이템의 거래 | 3-1 길 만들기 | +1,400 | 쿠션 1+ · 기회 절약 | 공 이동을 쓰는 타이밍을 생각하게 한다. |
|  | 3-2 위험의 값 | +2,000 | 위험 계약 | 위험 샷을 설명하고, 사용 가능한 아이템을 보장한다. |
|  | 3-3 지울 것인가 | +1,800 | 파울 세금 · 쿠션 2+ | 파울 제거를 아낄지 쓸지 판단한다. |
|  | 3-4 거래의 끝 | +2,500 | 위험 계약 · 기회 절약 | 위험 샷을 안전하게 준비하는 흐름을 시험한다. |
| 4. 마지막 계약 | 4-1 숙련 | +2,000 | 쿠션 2+ · 기회 절약 | 기본 실력을 확인한다. |
|  | 4-2 누적의 무게 | +2,200 | 쿠션 1+ · 파울 세금 | 누적 점수를 지키는 선택을 요구한다. |
|  | 4-3 마지막 유혹 | +3,000 | 위험 계약 · 파울 세금 | 큰 점수를 노리되 총점 초기화 위험을 드러낸다. |
|  | 4-4 최종 테이블 | +3,500 | 쿠션 2+ · 기회 절약 · 파울 세금 | 이미 배운 조건만으로 최종 시험을 만든다. |

챕터 전환 시 누적 총점과 보유 자원을 보여주고, 이전 챕터의 성공이 다음 챕터의 출발 상태가 됐다는 사실을 명확히 알린다. 목표가 높아지는 것만으로 난도를 만들지 않는다. 공 배치와 파울 공 배치를 함께 조정하되, 정해진 한 해법을 강요하지 않는다.

## 안내 캐릭터 사용안

현재 저장소에는 `spr_assistant_pixel`이라는 정지 이미지 스프라이트가 등록돼 있다. 대사 시스템이나 화면 출연 로직은 아직 없다. 이 캐릭터를 **계약 안내자**로 쓰는 안을 제안한다. 이름과 성격은 아직 확정하지 않는다.

- 스테이지 시작: 목표 점수와 새 규칙을 **짧은 한 문장**으로 설명한다. 예: “이번에는 벽을 한 번 거쳐야 점수가 인정돼.”
- 새 아이템 획득 시: 효과, 사용 시점, 위험을 1~2문장으로 알려준다. 처음 한 번은 확인 후 닫는 설명을 보여주고, 이후에는 인벤토리에서 다시 볼 수 있게 한다.
- 플레이 중: 목표와 현재 규칙은 HUD에 고정하고, 캐릭터 대사는 필요한 사건에만 띄운다. 조준·충전·공 이동 중에는 화면을 가리거나 입력을 막지 않는다.
- 실패·성공: 왜 실패했는지 사실에 맞게 알려주고, 챕터 재시도 또는 다음 스테이지로 이어준다. “파울 때문에 이번 점수는 인정되지 않았어.”처럼 판정 이유를 말한다.
- 대사는 플레이어의 선택을 대신하지 않는다. 아이템 사용 여부나 샷 방향의 정답을 강요하지 않는다.

캐릭터의 첫 대사는 목적과 규칙을 알려주되 긴 설명을 피한다. 긴 설명은 일시정지 가능한 도움말에 넣는다. 현 스프라이트는 세로형 전체 인물 이미지이므로 게임 테이블 위에 그대로 배치하기보다 대화 패널에서 얼굴 또는 상반신이 읽히는 구도를 검토한다. 최종 크기와 위치는 1280×720 플레이 화면에서 가독성을 확인한 뒤 정한다.

## 구현 경계와 검증 기준

스토리 진행 상태(챕터·스테이지·목표 진행량·체크포인트), 스테이지 규칙 데이터, 캐릭터 대사 데이터, 화면 표시는 별도 책임으로 둔다. 기존 무한/클래식 모드의 저장 점수와 규칙을 바꾸지 않는다. 스토리 모드 저장 키는 별도로 둔다. 규칙 판정은 샷 종료와 점수 확정 순서에서 처리하고, UI는 확정된 상태를 읽어 표시한다.

구현 전에는 AGENTS.md에 따라 현재 메뉴와 게임 장면을 촬영한다. 구현 후 같은 해상도와 가능한 한 같은 입력으로 다시 촬영한다. 규칙 변경은 각 카드에 대해 같은 입력의 점수·기회·상태 차이를 기록한다.

검증해야 할 대표 사례: 스테이지 목표 초과 득점, 무효 득점, 일반 파울, 위험 샷 파울, 기회 0, 챕터 재시도, 아이템 소진, 설명 재열기, 무한/클래식 모드 회귀. 각 스테이지는 최소 한 번의 수동 클리어와 한 번의 실패 경로를 확인한다. 목표 플레이 시간과 클리어율은 실제 플레이 기록으로 조정한다.

## 다음 논의에서 결정할 사항

1. 안내 캐릭터의 성격과 플레이어와의 관계: 친절한 코치, 계약을 제시하는 진행자, 믿기 어려운 해설자 중 어떤 톤인가?
2. 챕터 전환 시 저장을 자동으로 할지, 한 번의 플레이 중 체크포인트로만 둘지.
3. 스테이지 입장 시 기회가 1회 이하이거나 필수 아이템이 없을 때, 최소 자원을 보장할지.
4. `위험 계약` 스테이지의 아이템 보장 방식과 실패 후 재도전 상태.
5. 점수와 기회 목표치, 공 배치, 대사 길이는 플레이 테스트로 조정한다.
