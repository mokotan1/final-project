# 스토리 시작 이미지 기록

날짜: 2026-10-16 · 화면 기준: 1280×720

## 작업 전

`before/menu-archived-2026-10-15.png`와 같은 이름의 MP4는 2026-10-15에 Runner로 촬영한 메뉴 자료의 복사본이다. 이번 변경 직전 화면을 새로 촬영한 자료는 아니다. 변경 전 `Build/verify_project.win` 실행을 시도했지만 Windows의 시스템 DLL 재할당 오류로 Runner가 시작되지 않아 새 스크린샷과 영상은 얻지 못했다.

## 변경

- 사용자가 제공한 `Sprite-0003.png`를 원본 해상도 1280×720 그대로 `spr_story_opening`에 등록했다.
- 메뉴에서 스토리를 선택하면 먼저 이미지를 전체 화면으로 보여 준다. 클릭·Enter·Space로 대전을 시작하고 Esc로 모드 선택 화면에 돌아간다.
- 첫 실행의 스토리 도입 대사 뒤에도 같은 이미지를 보여 준 다음 첫 대전으로 이동한다.

## 작업 후 확인

`after/story-opening-sprite-resource.png`는 등록한 PNG 리소스의 복사본이며 실제 게임 화면 캡처가 아니다. 정적 프로젝트 검사와 GameMaker Igor VM 컴파일은 통과했다. 새 빌드로 Runner 실행을 다시 시도했지만 같은 DLL 재할당 오류가 발생했다. 따라서 작업 후 실제 게임 스크린샷과 영상은 없으며, 입력 전환과 화면 표시를 런타임에서 확인하지 못했다.
