# 바텐더 아이템 선택 우선순위 수정 (2026-10-27)

## 변경 전

- `before/story-initial.png`, `before/story-flow.mp4`는 바로 앞 파울공 복원 작업의 수정 후 Runner 자료를 복사했다. 이 작업의 수정 전 빌드 SHA-256은 `ABCD01F3918EDB33E74B8233A5F65EE2B7160E6E3B962A2A17E2C758D253CBE7`이다.
- 파울공이 하나라도 있으면 바텐더는 샷의 안전성이나 기대 점수를 확인하기 전에 파울 제거를 구매했다. 파울공이 턴 종료 때 돌아오므로 같은 선택이 반복될 수 있었다.
- `before/runtime-test.txt`에는 안전한 고득점 후보에서도 파울 제거를 구매하고, 위험 샷 조건을 충족해도 제거를 우선하는 실패(`ai-unblocked-no-remove`, `ai-risk-before-remove`)가 기록됐다.

## 변경 후

- 바텐더는 예상 득점이 낮고 선택한 샷 경로가 파울공에 막힐 때만 파울 제거를 구매한다. 경로 위험은 기존 `story_ai_ray_foul_risk` 판정으로 확인한다.
- 안전한 득점 후보에서는 아이템을 쓰지 않는다. 손님 리드가 100,000점 이상이고 위험 샷 조건을 충족할 때는 파울공이 단순히 존재한다는 이유로 위험 샷을 포기하지 않는다.
- `after/runtime-test.txt`는 안전한 샷·막힌 샷·위험 샷 선택과 기존 50합 회귀의 Runner PASS 기록이다. 수정 후 빌드 SHA-256은 `270CD52D003EE04BB9522876A4FBBAE0FD5F088EC82890C0FF951A848519D730`이다.
- `after/story-initial.png`, `after/story-flow.mp4`는 수정 후 빌드를 같은 스토리 모드·1280×720 화면·입력으로 촬영했다. 화면 영상은 특정 아이템 선택 상태를 주입하지 않으므로 선택 분기의 비교에는 전후 Runner 테스트 결과를 사용한다. 사용자가 추가 플레이 검증을 진행하기로 했다.
