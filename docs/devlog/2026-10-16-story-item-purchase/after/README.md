# 수정 후 촬영 불가

2026-10-16, 스토리 대전 1280×720. Igor VM 컴파일은 통과했습니다. 새 `Build/final_project.win`에 대해 `tools/capture_story_ai.ps1` 실행을 시도했지만 Windows가 Runner.exe 시작 전 “잘못된 DLL 재할당” 오류를 반환했습니다. 스크린샷·영상은 촬영되지 않았습니다. 수정 전과 같은 환경 장애입니다.

코드 변경: 스토리 대전 HUD에 구매 항목을 표시하고 1/2/3키 또는 클릭으로 점수 구매를 시도합니다. 현재 첫 판 승리 목표는 300점이므로 공 이동(200점)만 일반 플레이에서 구매 가능하며 400/800점 아이템은 후속 스토리 판이 연결되기 전에는 도달할 수 없습니다.

대사: 문서의 1-1 시작·도움말·승리 대사를 연결했습니다. 수정 후 최종 빌드에도 같은 캡처를 재시도했고 DLL 오류가 반복됐습니다. 실제 화면·조작 검증은 수행할 수 없었습니다.
