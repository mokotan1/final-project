# 바텐더 큰 점수 차 실패 연출 조정 (2026-10-28)

## 작업 전

- `before/story-initial.png`, `before/story-final.png`, `before/story-flow.mp4`: 수정 전 정식 50합 경기를 1280×720, 240프레임으로 촬영했다. 180프레임째 손님 샷 입력을 보냈다.
- 기존 규칙은 바텐더가 100,000점 이상 앞서면 적격 턴마다 25% 확률로 위험 샷을 사며, 목표 공 반대쪽으로 치고 샷 종료 때 누적 점수를 0으로 만들었다. 전용 반응 대사도 표시했다.
- 첫 촬영은 Runner가 23프레임에 종료됐고, `before-retry/`는 상대 경로 오류 창을 촬영한 무효 자료다. 유효 자료는 절대 경로로 다시 촬영한 `before/`에 있다.

## 변경

- 점수 차가 처음 100,000점 이상 벌어진 합부터 1~10합 중 한 합을 균등하게 무작위 예약한다. 50합 종료가 가까우면 남은 합 안에서 발동한다.
- 예약된 샷은 기존 선택 방향에서 8~18도 무작위로 빗나가게 친다. 전용 실패 대사는 제거하고 일반 샷 반응을 사용한다.
- 위험 샷의 기존 누적 점수 소실 규칙은 유지한다. 즉 예약된 위험 샷이 실패하면 바텐더 점수는 0이 된다.

## 작업 후와 확인

- `after/story-initial.png`, `after/story-final.png`, `after/story-flow.mp4`: 같은 모드, 화면 크기, 프레임 수와 입력 절차로 촬영했다. 난수에 따라 공 배치는 다르다.
- 두 영상은 100,000점 격차를 만들지 않으므로 실패 이벤트의 직접적인 화면 비교는 아니다. 변경 전후 규칙 상태는 `tools/story_50_runtime_harness.gml`의 99,999점 경계, 10합 예약 범위, 예약 합 발동, 경기당 1회 검사로 기록했다.
- Igor VM 컴파일 및 `python tools/test_story_versus.py`가 통과했다. Runner 하네스 단독 실행은 종료되지 않아 결과를 확인하지 못했다. 실제 플레이 체감 검증은 사용자가 맡기로 했다.
