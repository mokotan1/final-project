# 스토리 시작 안내 문구

날짜: 2026-10-16 · 기준 화면: 1280×720

## 작업 전

`before/user-reference.png`는 사용자가 제공한 시작 화면 이미지다. 이번 작업에서 게임을 직접 촬영한 자료는 아니다. 코드 수정 전 `Build/final_project.win`으로 GameMaker Runner 실행을 시도했으나 Windows의 `잘못된 DLL 재할당` 오류로 창이 열리지 않아 게임 화면과 영상을 촬영하지 못했다.

## 변경

스토리 시작 이미지 하단 중앙에 `시작하려면 클릭하세요`를 추가했다. 글자 밝기는 시간에 따라 반복해서 변한다. 메뉴에서 스토리를 선택했을 때와 첫 실행 도입 대사가 끝났을 때 같은 안내를 보여 준다. 기존 클릭·Enter·Space 시작 입력은 유지된다.

## 작업 후 확인

GameMaker Igor VM 컴파일, 프로젝트 구조 검사, 한글 픽셀 글꼴 검사를 통과했다. 새 빌드로 Runner 실행을 다시 시도했지만 같은 DLL 재할당 오류가 발생했다. 따라서 `after/`에 실제 게임 스크린샷이나 영상은 없으며, 화면 배치와 깜빡임을 런타임에서 확인하지 못했다.
