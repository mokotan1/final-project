# Unity 첫 실행 인트로 대조 (2026-11-04)

## 변경 전
- `before/intro.png`: Unity StoryIntro 씬 PlayMode, 1280×720 Game View 실제 캡처. 시작 이미지를 배경으로 첫 대사를 중앙에 표시한다.
- GameMaker `obj_story_intro`는 야경·캐릭터·하단 대사 패널에서 여섯 대사를 표시한 뒤 별도 시작 이미지를 보여준다. 첫 대사의 최근 실제 Runner 캡처는 확인되지 않아 원본 GML을 기준으로 삼았다.
- Unity Pipeline의 캡처 기능은 PNG만 지원한다. 이번 작업 전 실제 조작 영상은 촬영하지 못했다. 영상이나 합성 이미지를 게임 녹화로 표시하지 않는다.

## 변경 후와 검증
- `after/intro.png`, `after/opening.png`: Unity 플러그인의 실제 Game View 캡처. 첫 대사와 여섯 대사 뒤 별도 시작 화면을 기록했다.
- 캡처 도구가 1280×720 PNG를 저장했지만 실제 Game View 렌더 크기는 1083×523으로 확인됐다. 화면 하단과 오른쪽이 잘려 이 이미지는 1280×720 전체 배치 일치의 증거가 아니다. 변경 전 캡처의 실제 렌더 크기도 별도 확인되지 않았다.
- 기존 Canvas 및 텍스트 오브젝트를 재사용해 야경·바텐더·대사 패널과 원본 시작 이미지를 구성했다. 시작 시 0.25초 입력 잠금을 적용하고 여섯 대사 후 추가 입력으로 경기에 진입한다.
- Unity 컴파일 성공, PlayMode `StoryIntroParityTests` 1/1 PASS. 대사와 시작 화면 전환은 메서드 직접 호출로 검사했으며 실제 키보드·마우스 입력 또는 영상을 검증한 것은 아니다. 씬을 다시 연 후 야경·캐릭터·시작 화면의 이미지 참조가 존재하는 것을 확인했다.
- 최초 테스트는 기존 PlayerPrefs `story.story_intro_seen` 값을 백업하지 않고 true로 저장했다. 작업 전 값이 확인되지 않아 복원하지 않았다. 이후 테스트는 기존 값의 존재 여부와 값을 백업·복원하도록 수정했다.
