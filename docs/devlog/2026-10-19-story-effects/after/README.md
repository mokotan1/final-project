# 작업 후 Runner 촬영

2026-10-19, `Build/final_project.win`을 일반 데스크톱 권한의 Runner로 실행하고 메뉴에서 스토리 모드를 직접 선택했다. `tools/capture_existing_runner.ps1 -Frames 240`으로 1280×720 화면 240프레임을 촬영했다. `initial.png`, `final.png`, `story-break.mp4`는 실제 Runner 출력이다. 첫 촬영은 입력이 전달되지 않아 메뉴 화면만 담겼고, 같은 파일명으로 스토리 장면을 다시 촬영해 교체했다. 최종 화면은 대사 종료 후 테이블을 보여준다. 이 자료는 실행과 촬영 확인이며, 연출 변경의 요구사항 충족 여부는 별도 검토가 필요하다.
