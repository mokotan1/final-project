# 엔드리스 연출을 스토리 경기에 적용

## 작업 전

- `before/story-before.png`와 `before/story-before.mp4`는 직전 작업에서 사용자가 직접 실행한 Runner의 실제 스토리 화면·영상 사본이다. 1280×720 게임 클라이언트를 10fps로 촬영한 19.7초 영상이다.
- 영상에는 대사 종료 뒤 AI 브레이크 샷으로 중앙 공이 흩어지는 장면이 있다. 쿠션·득점·파울 연출이 스토리 HUD에서는 엔드리스와 같게 표시되지 않는 현재 상태를 확인할 비교 자료다.

## 작업 후

- 스토리 모드도 엔드리스·클래식이 쓰는 쿠션 링과 배율 문구, 득점 팝업, 큰 점수 패널·슬롯 음향, 파울 붉은 효과의 갱신·그리기 경로를 사용하도록 연결했다.
- 스토리 규칙에서 같은 구조의 효과 데이터를 생성한다. 스토리 점수·위험 샷 배율·파울 감점에 맞춰 값이 표시되며, 승부가 끝나도 효과 수명이 진행되도록 했다.
- `tools/test_story_versus.py`, `tools/validate_project.py`와 GameMaker Igor VM 컴파일을 통과했다.
- 첫 `after/story-break.mp4` 촬영은 24초 전체가 메인 메뉴 화면이라 스토리 연출의 작업 후 증거로 사용할 수 없다. 스토리 경기 화면에서 재촬영해야 한다.
