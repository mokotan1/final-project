# 첫 실행 스토리 도입 기록

날짜: 2026-10-15 · 화면 기준: 1280×720

## 작업 전

프로젝트의 첫 룸은 `rm_menu`였다. `before/menu-archived.png`와 `before/menu-archived.mp4`는 같은 날 이전 작업에서 Runner로 실제 촬영한 **과거 메뉴 상태**를 복사한 참고 자료다. 이번 수정 직전 버전을 새로 촬영한 자료가 아니므로 작업 전후 화면의 직접 비교 증거로 사용하지 않는다.

이번 작업 직전 소스를 GameMaker Igor VM으로 컴파일하는 데는 성공했다. 그러나 `Runner.exe -game Build/final_project.win` 실행이 Windows의 `{Illegal System DLL Relocation}` 오류로 실패해 현재 상태의 새 스크린샷과 영상을 촬영하지 못했다.

## 변경

- 첫 룸 `rm_story_intro`에서 저장 기록이 없는 플레이어에게 바텐더와 술값 내기 도입 대사 6줄을 보여 준다. 마지막 대사 뒤에는 300점 목표의 첫 대전으로 이어진다.
- 도입을 마친 이후 실행에서는 메뉴로 이동한다. 메뉴의 모드 선택 화면에서 스토리 첫 대전을 다시 시작할 수 있다.
- 첫 대전에서는 바텐더가 처음 두 차례 샷을 양보한다. 300점 도달 또는 손님의 기회 소진으로 대전을 끝내고 메뉴로 돌아간다.
- Google Sheet에는 16스테이지 대사 초안을 별도로 정리했다. 현재 게임에 연결된 것은 도입과 300점 첫 대전뿐이다.

## 작업 후 검증과 촬영 제한

GameMaker Igor VM 컴파일과 정적 프로젝트 검사, 모드 검사, 한글 글리프 검사, AI 규칙 검사는 통과했다. Runner를 다시 실행해 같은 조건에서 촬영하려 했지만 동일한 DLL 재배치 오류로 실패했다. 따라서 `after/`에 실제 게임 화면이나 영상은 없다. 도입 문구의 화면 배치, 대전 결과, 저장 후 재실행 동작은 런타임에서 확인되지 않았다. 촬영하지 않은 자료를 결과 화면으로 표시하지 않는다.
