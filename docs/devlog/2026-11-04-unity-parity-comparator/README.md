# Unity 이식: 물리 추적 비교 누락 수정 (2026-11-04)

## 확인된 문제

GM Runner와 Unity의 프레임 비교기가 역할 이름만 딕셔너리 키로 사용해 같은 `Foul` 역할의 공 두 개 중 마지막 공만 비교했다. 따라서 기존 312°/15 MATCH는 첫 번째 파울 공의 궤적을 검증하지 못했다.

## 변경 및 검증

- 같은 역할의 공을 추적 배열에서 나타난 순서별로 비교하도록 수정했다. 이 방식은 양쪽 추적에서 같은 역할의 공 순서가 일관된다는 전제에 의존한다.
- 첫 번째 파울 공의 위치 변경과 삭제를 검출하는 회귀 검사를 추가했다. 수정 전 두 검사가 실패했고 수정 후 3개 검사 모두 통과했다.
- 기존 GM Runner 및 Unity 저장 추적 312°/15를 수정된 비교기로 재비교해 MATCH를 확인했다. 이는 저장된 한 샷의 좌표·속도·lock과 outcome 비교이며 신규 런타임 측정은 아니다.
- 게임 동작과 화면은 수정하지 않아 전후 게임 캡처 대상이 아니다.

## 남은 과제

- 프레임 이벤트와 step 번호는 비교하지 않으며, 파울 공 순서의 안정성은 추가 사례에서 확인해야 한다.
- Unity의 `ExportGolden_312x15_ForPythonMirror` 테스트는 기준 파일을 덮어쓰므로 테스트 순서에 따른 회귀 은폐 가능성이 있다. 별도 수정과 Unity 실행 검증이 필요하다.
- 추가 파울·충돌·정산 샷의 GM Runner 실측과 Unity 전체 플레이 경로 검증은 아직 수행하지 않았다.
