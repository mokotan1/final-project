# 바텐더 대화창 가독성 개선 (2026-11-03)

## 변경
- 스토리 대전의 대화 패널을 확대하고 이름과 본문을 분리했다. 갈무리 본문을 22px 기준으로 출력하고 폭에 맞춰 줄바꿈한다.
- 기존 `spr_assistant_dialogue`의 말하기·웃음·놀람·걱정·안심 표정을 대사 ID에 따라 선택한다. 새로 제작한 스프라이트는 없다.
- 대사와 턴 배너가 동시에 보일 때 배너를 패널 아래로 옮겼고, 턴 건너뛰기 안내도 분리했다. 경기 중에도 대화창이 유지되는 기존 동작은 그대로다.

## 전후 자료
- `before/story-initial.png`, `before/story-flow.mp4`: 수정 전 Runner 화면과 영상. `after/story-initial.png`, `after/story-flow.mp4`: 수정 후 같은 스토리 진입 절차의 화면과 영상.
- 두 촬영 모두 1280×720 클라이언트이나 보조 모니터 폭이 1080px여서 오른쪽 일부가 검게 잘렸다. 따라서 오른쪽 HUD와 대화창 경계는 이 촬영으로 검증할 수 없다.
- `before/user-screenshot.png`는 사용자가 제공한 참고 이미지이며 이번에 직접 촬영한 자료가 아니다.

## 검증 및 남은 확인
- GameMaker Igor VM 컴파일 성공. 스토리 대전, 50합, 대사 일치, 프로젝트 리소스, 갈무리 글리프 검사 통과.
- 수정 후 캡처에서 바텐더 상반신 및 확대된 첫 규칙 문장을 확인했다. 긴 도움말과 각 표정, 대사와 턴 배너 동시 표시, 플레이 중 공·조준선 가림은 전체 화면 실기 확인이 필요하다.
- 기존 `Build/final_project.win`은 Igor 컴파일 과정에서 현재 소스로 갱신됐고, 동일 결과를 `Build/bartender_ui.win`으로도 저장했다.
