# 모드 설명 표정 경계 수정

## 작업 전

`before/user_normal_match.gif`는 사용자가 제공한 실제 실행 화면이다. ENDLESS와 CLASSIC 버튼을 누를 때 입 주변에 붙인 말하기 프레임의 사각형 경계와 턱 음영이 눈에 띈다. GIF는 1077×515로 화면 일부만 담고 있다.

## 작업 후

기존 `spr_assistant_desk_talk`에서 복사하는 얼굴 영역을 45×39에서 32×27 픽셀로 줄여 턱 윤곽과 주변 음영을 제외했다. 캐릭터 idle과 말하기 프레임의 위치·재생 시간은 유지했다.

이 환경의 GameMaker Runner는 Windows DLL 재할당 오류로 실행되지 않아 같은 장면의 작업 후 영상은 촬영하지 못했다. 실제 게임 화면에서 경계가 충분히 사라졌는지는 확인이 필요하다.
