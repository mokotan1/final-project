# 스토리 대전 고득점 기준 수정

날짜: 2026-10-15 · 화면: 1280×720

## 수정 전

한 샷의 확정 유효 득점이 400점 이상이면 바텐더가 고득점 대사를 했다. 사용자가 의도한 고득점은 **1,000점 초과**였다. 수정 전 상태를 Runner로 촬영하려 했으나 Windows의 `{Illegal System DLL Relocation}` 오류로 실행되지 않았다. 따라서 `before/`에 실제 화면이나 영상이 없다.

## 수정 후

손님과 바텐더 모두 한 샷에서 **확정된 유효 득점이 1,000점을 초과**해야 고득점 대사가 나온다. 1,000점 이하는 일반 득점 반응으로 보낸다. 현재 점수식 `100×2^쿠션 수`에서는 4쿠션의 1,600점부터 해당한다. 결과 화면에서도 같은 반응을 사용한다.

Google Sheet와 로컬 JSON/CSV의 발동 조건을 함께 수정했다. `EVT-BARTENDER-HIGH-02`의 400점 언급을 없앴고, 400·800점으로 첫 대결이 종료돼도 자연스러운 일반 득점 문구로 바꿨다. 대사 ID·문구 일치 검사, 한글 글리프 검사, GameMaker VM 컴파일을 통과했다.

수정 후 Runner 촬영도 동일한 DLL 오류로 실패했다. `after/`에 실제 화면이나 영상은 없다. 1,000점 경계의 런타임 반응은 확인되지 않았으며, 촬영하지 않은 자료를 화면 증거로 표시하지 않는다.
