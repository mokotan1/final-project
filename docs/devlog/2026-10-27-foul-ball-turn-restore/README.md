# 파울공 임시 제거 후 턴 종료 복원 (2026-10-27)

## 변경 전

- 수정 전 빌드(SHA-256 `5DA45597F5CC5CC909901CDC923F1198B31E552310761E557D908E2C27811097`)의 스토리 경기 화면과 100프레임 영상을 `before/`에 촬영했다.
- `before/runtime-test.txt`: AI·손님이 파울 제거 아이템을 사용한 뒤 턴을 마쳐도 원래 좌표에 파울공이 돌아오지 않아 `ai-restore-position`, `player-restore-position`이 실패했다. 게임 화면 영상에는 아이템 구매 장면이 없으므로 이 상태 기록을 규칙 비교에 사용한다.

## 변경 후

- 구매 직전 존재하는 파울공 각각의 좌표를 저장하고, 현재 턴에는 전부 치운다. 샷 종료, AI의 샷 없는 턴 종료, 일반 턴 전환 시 저장된 좌표에 다시 만든다. 턴 중 새로 생긴 파울공은 유지한다.
- 도움말, 아이템 설명, 로컬 대사 데이터에 턴 종료 복원 규칙을 반영했다.
- 수정 후 빌드(SHA-256 `ABCD01F3918EDB33E74B8233A5F65EE2B7160E6E3B962A2A17E2C758D253CBE7`)를 같은 스토리 모드·1280×720 화면·입력으로 `after/`에 촬영했다. 실제 아이템 복원 판정은 `after/runtime-test.txt`에 기록했다.
- 자동 Runner 하네스는 AI 패스와 손님 샷 종료에서 원래 두 좌표의 복원, 턴 중 새 파울공 유지, 50합 회귀를 PASS로 기록했다. 사용자가 직접 추가 검증을 진행하기로 했다.
